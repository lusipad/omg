# 用安装点搭建机械装配

同一只转台转 90°、同一只滑台进给 40 mm，调换它们的上下游位置，工具尖端会落在两个不同的世界坐标。可先打开完整工程，核对预览后确认，再在装配与仿真中分别运行两条装配。工程替换会覆盖当前工作区，需要保留的工程可先导出。[打开转台与滑台工程预览](https://lusipad.com/omg/?view=resources&source=assemblies/mounts/project.twin.json) · [完整工程 JSON](https://lusipad.com/omg/assemblies/mounts/project.twin.json)

## 从三包开始安装

1. 下载三个设备包，在 **工程资源** 选择这三个 JSON，核对制造商“构元示教”、修订“1.0”后安装。也可将每个文件的链接分别粘贴到导入框。[RZ-转台](https://lusipad.com/omg/assemblies/mounts/turn.device.json) · [LX-滑台](https://lusipad.com/omg/assemblies/mounts/slide.device.json) · [T20-工具](https://lusipad.com/omg/assemblies/mounts/tool.device.json)
2. 打开机械装配编辑器，给新装配命名。先在初始实例的 **设备包** 中选择转台，再点 **添加实例** 添加滑台和工具。按下表填写 **实例标识**，根节点接世界坐标系，其余节点用 **父实例** 和 **父安装点** 连接。[用机械部件新建装配](https://lusipad.com/omg/?view=workbench&target=mechanism-new)
3. 将 **输出实例** 设为 `tool`，**输出安装点** 设为 `tip`。填写关节指令后点 **保存并计算**，在目标姿态读取世界坐标 X、Y、Z，单位为毫米。

| 节点 ID | 设备与指令 | 安装到哪里 |
| --- | --- | --- |
| `turn` | RZ-转台，本地 Z 轴 +90° | 世界 |
| `slide` | LX-滑台，本地 X 轴 +40 mm | `turn.out` |
| `tool` | T20-工具，固定连接 | `slide.out` |

两件运动部件的 `out` 在各自零位的关节原点。工具的 `tip` 固定在自身原点沿本地 X 方向 20 mm 处。转台作为根时，滑台行程和工具偏置一同转向世界 +Y。也可直接导入上述装配的关系 JSON，沿用已安装的三份设备包。[转台在前的装配关系](https://lusipad.com/omg/assemblies/mounts/turn-slide.assembly.json)

## 交换转台与滑台

在同一工程新建第二条装配，先把 `slide` 接世界，再将 `turn` 接到 `slide.out`，最后将 `tool` 接到 `turn.out`。选取相同的 `tool.tip`，保持原有指令。滑台现在直接沿世界 +X 移动，转台只带动下游的工具偏置。[滑台在前的装配关系](https://lusipad.com/omg/assemblies/mounts/slide-turn.assembly.json)

| 从根到工具 | 进给与偏置在世界坐标中的方向 | 目标姿态下的工具尖端 (X, Y, Z) |
| --- | --- | --- |
| 转台 → 滑台 → 工具 | +Y 40 mm，再 +Y 20 mm | (0, 60, 0) mm |
| 滑台 → 转台 → 工具 | +X 40 mm，再 +Y 20 mm | (40, 20, 0) mm |

## 把滑台与工具另存为一个子装配

1. 打开刚保存的“转台 → 滑台 → 工具”装配，保留滑台指令 40 mm 和输出 `tool.tip`。打开 **封装子装配**，在 **封装范围** 选择 **slide 及其后代**。此子树由滑台及其下游工具组成，在自身基准系中的尖端位置为 (60, 0, 0) mm。
2. 填写制作者或厂商、子装配型号和修订，点 **导出子装配包**。发布的示范包使用“构元示教 / LX-T20-子装配 / 1.0”，随包带有内部两件设备、连接关系、输出选择和内部指令。可在工程资源中核对并增量安装。[打开滑台与工具子装配预览](https://lusipad.com/omg/?view=resources&source=assemblies/mounts/slide-tool.package.json) · [下载子装配包](https://lusipad.com/omg/assemblies/mounts/slide-tool.package.json)
3. 在空工程中先导入转台的独立设备包，再导入刚下载的子装配包。新建装配，把转台 `turn` 接世界，把刚安装的子装配作为节点 `unit` 接到 `turn.out`，将观察输出设为 `unit.out`。
4. 给转台 +90°，保留子装配内的 40 mm 进给，目标位置仍是 (0, 60, 0) mm。在这个父装配中把 `unit/slide` 改为 0 mm，重新运行，位置变成 (0, 20, 0) mm。20 mm 来自子装配内工具的固定偏置。

## 用自己的资料制作部件包

可以复制上面的转台、滑台或工具 JSON，按自己的资料填写 `manufacturer`、`model`、`revision`。在 `source` 记录图纸、手册或测量记录的标题、页码或图号和原文摘录。公开资料填写其网址，本地记录采用 `kind: "local"` 并将 `url` 留空。也可在设备资料区复制 AI 提取提示词，辅助整理资料中明确给出的安装参数，再在设备包预览中逐项核对。

- `mechanics.input` 是部件零位时，输入安装点相对于本体坐标系的位姿。每个安装帧都要填写 `positionMm` 和 `quatWxyz`。前者是三轴毫米坐标，后者是单位四元数，顺序为 w、x、y、z。组装时父输出与子输入对齐，子输入的位移和转角会一起取逆。图纸明确两者同原点、同方向时，才可填写 (0, 0, 0) 和 (1, 0, 0, 0)。[MuJoCo 局部坐标系约定](https://mujoco.readthedocs.io/en/stable/modeling.html#coordinate-frames)
- 在 `joint` 选择固定、旋转或直线连接。旋转关节用 `hinge` 和 `deg`，直线关节用 `slide` 和 `mm`。这两种活动关节都需填写本地轴 `axis`、单位 `unit` 和由下限、上限构成的 `range`。固定连接只填 `type: "fixed"`。
- `outputs` 列出运动体上的安装点。每个点有自己的 `id` 和位姿，关节运动时随本体移动，可用来连接下一级或观察工具尖端。图纸缺少安装偏移、方向或限位时，在资料记录中标为待补，取得图纸尺寸或测量值后再填。工作台示意图中的线长和符号大小只用于显示。

## 用同一编辑器运行 SO-101 肩部

打开 SO-101 肩部工程预览。确认后，在同一机械装配编辑器选择“SO-101 肩部两关节 · 肘关节原点”。`base` 为固定基座，`shoulder_pan` 与 `shoulder_lift` 两关节串联。观测点 `shoulder_lift.elbow_flex` 取自上游肘关节铰链中心。两个转轴都写为本地 +Z，它们在世界坐标中的朝向由各自父安装点的四元数决定。[打开 SO-101 工程预览](https://lusipad.com/omg/?view=resources&source=assemblies/mounts/so101.twin.json) · [SO-101 工程 JSON](https://lusipad.com/omg/assemblies/mounts/so101.twin.json)

依次设置两关节指令并读取目标姿态。下表取自完整上游六关节模型的 MuJoCo 正运动学，后四关节保持在 0°。自动校验要求通用装配结果与完整模型的空间距离小于 0.0001 mm。表内坐标保留六位小数。

| 肩部回转 `shoulder_pan` | 肩部抬升 `shoulder_lift` | 肘关节中心世界坐标 (X, Y, Z)，mm |
| ---: | ---: | --- |
| 0° | 0° | (97.234500, −18.277809, 229.170000) |
| +30° | −25° | (36.799264, −19.929888, 230.456379) |
| −45° | +35° | (135.129637, 70.445615, 192.751805) |

设备包保存了原始刚体名、安装偏移、四元数、关节轴和来源修订。这里计算给定关节位置下的几何姿态。要查看原模型中重力、力矩和控制器作用下的实际运动，可打开完整六轴示例。[安装点来源与单位换算](https://lusipad.com/omg/assemblies/mounts/SOURCE.md) · [上游固定版模型](https://github.com/TheRobotStudio/SO-ARM100/blob/a758567c3978dfeefe282ede0500085a48fe8f78/Simulation/SO101/so101_new_calib.xml) · [SO-101 六轴示例](https://lusipad.com/omg/?view=workbench&example=so101-follower)
