# 导入自己的模型和资料

在 **工程资源** 中选择文件、文件夹，或粘贴内容与链接。工作台识别格式并打开预览，确认后就能在同一张清单找到自己的设备、模型、资料和程序。从清单打开对象即可进入 **装配与仿真**。SO-101、Milo 和工程文件菜单也使用这套导入预览。[打开工程资源](https://lusipad.com/omg/?view=resources)

| 手头的资料 | 识别结果 | 确认后的用途 |
| --- | --- | --- |
| MJCF、URDF、模型目录或模型 ZIP | 物理模型 | 选择入口、编译试跑，确认后安装到模型库 |
| 单独的 STL、OBJ | 几何网格 | 选择米、厘米或毫米，核对尺寸后安装 |
| 一个或多个声明式设备 JSON | 设备包 | 核对来源和参数后安装。配套的驱动器与电机可一并选中并带入伺服轴，修订冲突时整批不写入 |
| 工程 JSON 或含工程清单的 ZIP | 完整工程 | 核对将被替换的设备、装配和模型。ZIP 会同时恢复原始资源 |
| CSV、TSV、含名称与数量列的单张 Markdown 表 | 通用物料清单 | 保存物料及来源，再绑定设备或模型。重复导入保留已有人工绑定 |
| Milo v1.5 采购指南、SO-101 单从臂采购表或完整 README | 相应机型的 BOM | 核对后送到对应工作台。Milo 按新库存复核已装轴，SO-101 保留已保存的动作路点 |
| TXT、Markdown、手册正文 | 设备手册 | 可编辑标题、来源和摘录，保存到资料库或直接带入设备资料表单 |
| NC、GCODE、可识别的程序原文 | Milo G 代码草稿 | 可先保存草稿。三轴装配齐全后，由用户在编辑器中启动运行 |

在 **粘贴内容或链接** 中可直接粘贴 AI 返回的 JSON 代码块，也可粘贴模型 XML 或带来源列的清单。设备与工程 JSON 共用 8 MiB 输入上限，普通资料文本为 2 MiB。手册可选摘最多 80,000 个字符归档，Milo 程序草稿最多 65,536 个字符。多份设备 JSON 可以同时选择，同一个模型的入口与配套资源也可以一起选择。不同工程或不同种类的独立资料请分次导入。

粘贴能直接下载的公开文件链接，会进入与本地文件相同的预览。浏览器需能跨域读取该地址。GitHub 文件页面可解析到原文件，Milo 官方采购指南页面会读取示例使用的固定版本。普通产品网页可以作为设备资料来源，再补充规格正文。完整版支持 PDF 提取和指定汇川官方站点的资料读取，Pages 上可复制 PDF 的相关章节后导入。[Milo 官方采购指南](https://millenniummachines.github.io/docs/milo_1.5/bom/sourcing_guide/) · [SO-101 单从臂采购表](https://github.com/TheRobotStudio/SO-ARM100/blob/a758567c3978dfeefe282ede0500085a48fe8f78/README.md#parts-for-one-follower-arm)

## 从物理模型开始

选择入口文件和依赖资源。单文件模型可以直接使用，含网格、纹理或子 XML 的项目适合用文件夹或 ZIP 保留相对目录。若有多个入口，选择本次装配使用的 XML 或 URDF。错误提示会指出缺少的资源或引擎拒绝的内容。

工作台从编译结果读取关节、执行器、控制范围和观测点。可以使用恒定控制，或按绝对到达时间给一组阶段目标。分段运行在每个物理步平滑改变控制输入，并从同一份仿真状态采样。选第二个参考点时，可以比较两个部位在同一时刻的高度变化。已安装的模型会保存最近一次成功运行的设置，随完整工程一起导出。被动动力学模型可以直接在重力等模型条件下演化。URDF 的可用关节和驱动能力取决于实际模型描述。[MuJoCo 建模参考](https://mujoco.readthedocs.io/en/stable/modeling.html)

从 **示例库 → 弹簧滑台** 可以试跑一份带预紧弹簧的 XML。运行 1 s，`push` 控制值为 0 时，`travel` 位移约为 0.06591 m。把控制值改为 0.5 后从初始状态重跑，位移约为 0.09142 m。也可以下载 XML，修改弹簧刚度、滑块质量或几何，再通过工程资源导入比较。[打开弹簧滑台](https://lusipad.com/omg/?view=workbench&example=spring-carriage) · [可修改的滑台 XML](../public/examples/spring-carriage.xml)

单独导入网格时须选择米、厘米或毫米。它会以固定几何保存，后续要模拟质量、关节、碰撞或驱动，请提供含这些定义的物理模型。模型包单文件上限为 32 MiB，整包上限为 64 MiB、512 个文件。

## 用开放机器人试跑

在 **示例库** 选择机器人，打开后点 **运行仿真**。工作台核对机器人模型包的大小和 SHA-256 后编译。试跑与调参都在临时预览中进行，点 **加入当前工程** 才会保存。工程已有相同物理模型时会沿用工程中保存的工况。也可以下载 ZIP 在其他浏览器导入。[浏览示例库](https://lusipad.com/omg/?view=examples)

| 模型 | 打开后可以试什么 | 内置工况的模拟结果 |
| --- | --- | --- |
| [Robotiq 2F-85](https://lusipad.com/omg/?view=workbench&example=robotiq-2f85) | 在上游带悬挂方块的场景将 `fingers_actuator` 分别设为 0 和 255，各运行 1 s | 两个指垫刚体原点在张开、闭合两次试算中的间距约为 98.38 mm 和 60.47 mm |
| [TurtleBot3 Burger](https://lusipad.com/omg/?view=workbench&example=turtlebot3-burger) | 观察车身 `base_footprint`，分别试左右轮同向和反向 | 同为 3 rad/s 时，1 s 后 X 方向前进 97.92 mm。左轮 3、右轮 −3 rad/s 时，1 s 后偏航约 −69.37° |
| [UR5e](https://lusipad.com/omg/?view=workbench&example=ur5e) | 从 `home` 姿态把肩部回转指令增加 0.2 rad，观察 `attachment_site` | 1 s 后，法兰原点与保持 `home` 的对照试验相差约 101.46 mm |
| [Open Duck Mini v2](https://lusipad.com/omg/?view=workbench&example=open-duck-mini-v2) | 在固定底座的位置伺服场景给 `head_yaw` 设 0.25 rad，其余 15 路保持零目标，观察左天线支架 | 0.4 s 时实际偏航约 0.2461 rad，左天线支架相对于零指令对照移动约 23.67 mm |
| [LeKiwi](https://lusipad.com/omg/?view=workbench&example=lekiwi) | 检查三轮和六个臂关节，在上游固定底盘的 URDF 中观察夹爪刚体的被动响应 | 0.1 s 内，夹爪刚体原点的高度从 134.21 mm 降到 119.03 mm |
| [Barkour v0](https://lusipad.com/omg/?view=workbench&example=barkour-v0) | 从上游 `standing` 关键帧开始，保持 12 个关节目标，观察机身与地面的相对运动 | 1 s 后，机身高度由 210.00 mm 变为 174.82 mm |

机器鸭来自 apirrone 的 Open Duck Mini 项目。其 ZIP 还带有浮动基座、力矩驱动的 `scene.xml`。要让它自主行走，还需接入上游单独提供的步态策略。LeKiwi 来自 SIGRobotics-UIUC，官方硬件把 SO 系列机械臂与三轮移动底盘组合。Barkour v0 来自 Google，所用物理描述由 MuJoCo Menagerie 提供。来源说明列出了固定提交、模型适配和许可证。[机器鸭来源](../public/robots/open-duck-mini-v2/SOURCE.md) · [LeKiwi 来源](../public/robots/lekiwi/SOURCE.md) · [Barkour 来源](../public/robots/barkour-v0/SOURCE.md)

## 从三个组件装配取放工位

1. 打开 [UR5e 取放工位](https://lusipad.com/omg/?view=workbench&example=ur5e-pick-place)。三个槽位分别选择机械臂、夹爪和工件。默认选择使用目录中的独立模型包和[30 mm 工件文件](../public/workcells/ur5e-pick-place/workpiece.xml)。也可以先把组件分别导入模型库，再在槽位中选取相同接口的本机组件。
2. 点 **组装取放工位**。装配器读取 UR5e 法兰 `attachment_site` 的位置和方向，把 2F-85 的 `base_mount` 固定到法兰上，方块独立放在台面。默认方块质量为 27 g，尺寸、质量和摩擦参数见工件文件。
3. 点 **运行仿真**，通过 **跳至动作阶段** 或回放游标查看下降、夹紧、上举、横移、放件和退让。默认观测点是方块中心，参考点是夹爪夹持中心 `grip_pinch`。**阶段观测记录** 的 ΔZ 从仿真开始计量，要判断夹紧后的滑移，应比较“夹紧保持”和“悬空保持”两行。
4. 复核默认工况：从 2.00 s 到 4.00 s，上举指令为 50 mm，夹持中心实际升高 **49.73 mm**，方块实际升高 **49.71 mm**，两者的相对垂向变化约 **−0.015 mm**。放件后方块比取件时沿 X 移动 **80.04 mm**，夹爪退让后工件留在台面。这些数值来自位置伺服和指垫接触的离线积分。用同一路径全程张爪重跑，方块在该举升阶段的高度变化约为 **0 mm**。

该配方使用 UR5e 法兰、2F-85 夹爪的关节/执行器接口和指定尺寸的自由方块。换用不同结构的工具时，需要定义相应安装接口并重新验证运动。组装后可以下载独立工位 ZIP，也可安装并通过 **导出完整工程 ZIP** 保存修改过的动作工况。[工位来源、假设与复验记录](../public/workcells/ur5e-pick-place/SOURCE.md)

## 从 BOM 或手册开始

选择 Milo v1.5 的官方 Markdown，在预览中点 **导入 Milo BOM** 后即可装轴。三轴就绪后可输入直线或圆弧程序，也可试跑圆槽示例，对照每层的刀尖轨迹与毛坯去料。[Milo v1.5 操作与算例](Milo-v1.5三轴铣床.md)

通用物料表要求名称和数量两列。下例使用 CSV，同样的列和值写成 TSV 或单张 Markdown 表时，会识别为同一批物料。需要把含清单的整篇文档作为手册归档时，在 **工程资源 → 手工录入或指定资料用途** 选择 **设备手册**。

```csv
物料名称,数量,单位,制造商,型号,备注
压力变送器,2,件,自研仪表,P-10,读取台架标定记录
非标夹具,1,套,,,等待结构模型
```

导入时先预览再保存。在供应商与型号能够唯一确定设备时，工作台可以匹配已安装修订。未匹配行会保留在清单中，可在物料详情选择已有设备包或物理模型，未知设备可以先记录资料。这里的绑定指向具体模型修订，装配中各部件的位置、约束和连线仍要由相应工程定义。

对具有线性关系的设备，可在物料详情选择 **按两点标定建模**。例如，记录给出压力 0 kPa 时输出 4 mA、100 kPa 时输出 20 mA，工作台会生成 `输出 = 0.16 × 压力 + 4`。核对两组数据、单位及来源后安装并绑定，进入仿真装配，输入 50 kPa 可读到 12 mA。模型在标定区间外沿同一直线外推。仅有本地测量记录时，可直接填写记录名称、位置和摘录。

对于更复杂的行为，可以从资料进入设备库进行已有规则或 AI 辅助提取，或在有动力学描述后绑定物理模型。公开静态站支持本地建档、标定和设备包导入，服务端模型调用与 PDF 提取在完整部署中提供。

## 保存与交换

物理模型原始文件放在当前浏览器的 IndexedDB 中，物料、绑定和装配记录保存在工程内。同一入口和内容可重复安装。分享一个模型时使用 **下载模型 ZIP**。迁移整个工程时，在 **工程文件** 中选择 **导出完整工程 ZIP**。接收者导入该 ZIP 即可恢复物料、绑定和物理资源。工程清单文字上限为 8 MiB，完整工程包的解压数据上限为 192 MiB。只有设备包或资料的工程仍可用 JSON 交换。
