- `npm run lint`：通过。

## 真实数据库闭环

`npm run test:persistence` 实际连接数据库并通过以下检查，临时账号和项目在测试结束后删除：

1. 三类模块定义已初始化；
2. 手动 CNC 模板生成三个真实组成模块；
3. 配置修改后保存并可重读；
4. 计算历史追加，步骤与输入摘要完整；
5. 非法部件角色和错误部件类别被 API 拒绝，且不追加历史；
6. 项目版本冻结并生成 SHA-256 内容摘要；
7. 工程包导出包含版本、计算和官方部件来源；
8. 自动整机需求在同一事务中创建模块、计算、来源候选、审计和 V1 快照，Z 轴姿态、候选角色与自动元数据均通过断言；
9. 另一账号读取项目被 `NOT_FOUND` 阻断。

部件种子实际执行 `npm run db:seed`，写入 3 个模块定义和 8 条官方来源部件修订。重复执行采用幂等更新，不覆盖后续人工或供应商确认状态。
