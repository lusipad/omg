# 从自己的 BOM 搭直线轴装配

在 **装配与仿真 → 新建装配** 中选择 **直驱丝杠伺服轴**。新建装配默认使用 Modelica，可从 BOM 选择驱动器、电机、丝杠和工作台，观察运动与受力。下文的双轴定位台使用 **离线折算惯量模型（原有算法）**。打开定位台工程会自动恢复该选择，从空白工程复建时可在 **求解模型** 中选择它。[新建直线轴装配](https://lusipad.com/omg/?view=workbench&target=assembly-new) · [Modelica 工作台与受力计算](Modelica直线进给轴.md)

## 先运行一台双轴定位台

在 **工程资源 → 粘贴内容或链接** 中粘贴下面的完整工程链接，核对预览后选择 **确认替换工程**。也可以下载 JSON 后用 **选择文件** 打开。如果要在已有工程中添加这台机构，请使用下一节的独立资料。[双轴定位台完整工程](https://lusipad.com/omg/assemblies/xy-stage/project.twin.json)

装配中只有一份 `slide` 模块定义。U 轴沿世界 X 正向安装，目标为 40 mm。V 轴沿世界 Y 正向安装，目标为 −10 mm。运行一次，在结果中选择 U 轴并将时间游标移至 100 ms。然后将 `slide` 的丝杠从 **5 mm 导程丝杠** 改为 **10 mm 导程丝杠**，保留两轴目标，再运行一次。

| U 轴的仿真读数 | 5 mm/rev 丝杠 | 10 mm/rev 丝杠 |
| --- | ---: | ---: |
| 100 ms 时位置 | 23.249 mm | 27.813 mm |
| 采样速度峰值 | 250.000 mm/s | 355.932 mm/s |
| 末端最终世界坐标，取至 0.01 mm | (40.00, −10.00, 0.00) | (40.00, −10.00, 0.00) |

两台机构接受同一位置指令。小导程方案先达到电机的额定转速，途中两条响应曲线因此分开。例中的两个导程和折算负载惯量比 1 是本例装配参数，驱动器与电机的额定数据及来源保存在各自的设备包中。

## 在自己的工程里逐步装配

1. 在 **工程资源** 导入 BOM。每条记录有名称和数量，本例采购两台驱动器、两台电机，并为两种丝杠各列两根。丝杠的数值写在 `导程(mm/rev)` 列中。[下载 BOM](https://lusipad.com/omg/assemblies/xy-stage/bom.csv)
2. 安装配套的两份汇川设备包，可同时选择两个本地 JSON，也可分别粘贴站内设备包链接。工作台按制造商和型号匹配 BOM 行。如一行可匹配多个修订，请在该行 **查看与绑定** 中选择。人工绑定替代件后，运行台会显示实际采用的型号。[SV660NS2R8I-FS-INT 驱动器](https://lusipad.com/omg/devices/inovance/SV660NS2R8I-FS-INT.device.json) · [MS1H1-40B30CB-A331R-INT 电机](https://lusipad.com/omg/devices/inovance/MS1H1-40B30CB-A331R-INT.device.json)
3. 在同一导入入口载入装配关系 JSON，或直接点 **新建装配** 自己选料、编排轴。这份 JSON 只加入它所描述的装配。相同装配 ID 会在预览中标明替换范围。也可以先定义关系，在编辑器右上角通过 **导入文件** 补充清单和设备包，继续填写当前草稿。工作台会逐项提示缺少的材料、设备绑定或导程。[下载装配关系](https://lusipad.com/omg/assemblies/xy-stage/assembly.json)
4. 同一模块可用于多根轴，每个轴实例都计入该装配的用量。如果两个实例合计需要两台电机而某条 BOM 只有一台，需补足库存或选用另一条物料。换用电机时，应核对电机设备包列出的配套驱动器。保存后可以从 **工程资源** 按装配名称重新打开。

## 装配关系中的字段

| 字段 | 含义 |
| --- | --- |
| `kind`、`schemaVersion` | 文件标识为 `linear-axis-assembly`，版本为 `1`。 |
| `id`、`name` | 稳定 ID 用于导入与更新，显示名称可自行命名。使用不同 ID 可以在同一工程保留多套设计。 |
| `modelRef` | Modelica 进给装配保存模型 ID 和版本。下文双轴定位台的旧工程省略此字段。 |
| `modules[].id` | 可复用的轴模块标识。一个模块的更改会作用于使用它的所有轴。 |
| `drive`、`motor`、`screw` | 各自引用一条 BOM 物料，可填唯一的名称或确切行 ID。驱动器和电机通过该行的绑定取到具体设备包。遇到同名物料，选择对应行 ID。 |
| `leadMmPerRev` | 丝杠每转对应的直线位移，单位为 mm/rev。填 `null` 时读取 BOM 的导程，清单缺值时可根据装配资料手动填写。 |
| `table` | Modelica 进给模块引用工作台 BOM 行，其移动质量来自带单位的清单字段或绑定的设备包。 |
| `loadInertiaRatio` | 原有算法用此参数记录折算到电机轴端的负载惯量与转子惯量之比。 |
| `axes[].id`、`module` | 实例的轴标识，以及它使用的模块 ID。轴数和名称由文件给出。 |
| `direction`、`targetMm` | 三维向量给出安装正方向，非零向量在求解时单位化。目标位移可正可负，单位为 mm。 |

位移由电机转数乘以导程得到。各轴同时从静止零位接受阶跃指令，末端坐标由每根轴的有向直线位移相加得到。驱动器与电机的额定参数及负载惯量进入原有伺服求解器，每次指令支持的电机转角为 ±3600°。这里输出独立直线轴的响应与末端运动轨迹。闭链、旋转关节、重力耦合、切削和现场反馈需要相应的机械模型或现场数据。[伺服模型及假设](汇川伺服轴示例.md) · [Thomson 对丝杠导程的定义](https://www.thomsonlinear.com/en/training/ball_screws/lead_vs_pitch)
