# 工程与验证边界

## 1. 状态定义

- **通过（passed）**：仅指列明的软件或测试活动已执行并留有证据。
- **来源已记录（recorded / source_recorded）**：已保存制造商官方资料定位信息，不代表供应商确认。
- **待完成（pending）**：尚未取得真实客户或工程师证据。
- **阻断（blocked）**：门槛未满足，相关能力不得作为已验证成果对外承诺。

参数化三维、公式测试通过和数据库保存成功，都不会自动提高供应商或设备验证状态。

## 2. 当前工程规则的用途

### 直线进给轴

当前初算合成重力分量、摩擦和惯性力，再估算丝杠转矩、转速、峰值功率及按占空比缩放的平均功率。行程字段用于需求记录，但没有据此完成丝杠临界转速、压杆稳定、DN 值、导轨寿命、丝杠寿命、定位精度或轴承跨距校核。

“平均功率 = 峰值功率 × 占空比”是早期热估算假设，不等同于电机 RMS 转矩或完整运动周期热计算。

### 旋转关节

当前初算使用：

- 重力转矩：`m × g × r × gravityFactor`；
- 总惯量：`m × r² + J_add`；
- 加速转矩：`J_total × α`；
- 经减速比和效率折算的电机转矩、转速与峰值功率。

附加惯量不能代替负载自身的 `m × r²`。质心半径为零时，仍需明确附加惯量来源。当前规则没有验证减速器反复峰值、平均转矩、急停转矩、倾覆力矩、扭转刚度、轴承寿命或制动保持能力。

### 驱动轮

当前初算合成坡度、滚动阻力和惯性力，再估算分配后的轮转矩、电机转矩、转速和峰值功率。轮径、轮体材料、附着系数、轴承布置和自制结构不属于供应商电机或减速器参数。

组合输出转矩的乘法估算只是初步选型参考，仍需按实际工作制、热容量、减速器连续与间歇限值、地面附着、制动和冲击工况复核。

### 整机自动分配与候选初筛

自动向导只把少量整机需求转换为初始模块参数，并调用与手动配置相同的初算规则：

- CNC 自动创建 X／Y／Z 三个直线轴，但当前三轴使用相同的初始运动质量、速度和加速度，未自动计入切削力、轴间质量叠加、主轴与滑台质量、临界转速或寿命。
- 六轴机械臂自动创建 J1—J6，并按工作半径比例分配初始质心半径；这不是完整刚体模型或逆动力学，连杆、电机和减速器自重不得由该比例虚构。
- 差速平台自动创建左右两个驱动轮，并均分初步牵引需求；左右轮只在首次生成时共享整车输入，之后修改一侧不会自动同步另一侧。
- 导程、减速比、目录转矩与转速仅用于候选初筛。没有有效候选时保持空缺并进入待确认项，不跨系列拼配，不虚构驱动器或完整订货型号。
- 自动创建成功只代表组成、初算、候选、审计和 V1 快照已持久化，项目仍为 `draft`，结果仍是可修改草案。

当前自动与手动流程都未自动处理模块间载荷传递、完整运动学／动力学耦合、共享控制器、整机电控架构或安全功能。自动分配不得描述为自动完成选型、详细设计或制造定版。

## 3. 没有由当前三维证明的内容

三维场景用于检查组成、尺度和运动布局。以下结论不能仅由三维重合或动画得出：

- 真实机械接口兼容；
- 强度、刚度、疲劳、模态或热变形合格；
- 公差、间隙、装配顺序和可维护性合理；
- 电缆、软管、拖链、润滑与防护设计完整；
- 碰撞、急停、制动或功能安全满足要求；
- 可直接加工、采购或实机运行。

制造设计仍需 CAD、接口图、工程图、公差、材料、工艺和审批记录。

## 4. 部件资料专项边界

- THK HSR 25R：官方在线 PDF 未标版本日期，精度、预压、密封和寿命仍需确认。
- HIWIN Super S：当前只记录系列级资料，具体丝杠型号的额定载荷、导程和精度未录入，不能作为型号级选型。
- Panasonic MSMF012L1T1：配套驱动器、电缆和实际热工作制仍需确认。
- Delta ASDA-A2 组：官方下载需要条款确认，完整订货字符、编码器类型和文件版本一致性需人工复核。
- Harmonic Drive CSG-25-100-2A：已定位目录为 rev 03-06，版本偏旧，必须索取现行工程数据表。
- Nabtesco RV-25N：最终减速比、输入接口、机匣图纸、润滑和寿命仍需确认。
- maxon EC-i 40 与 GP 42 C：电机—减速器接口、驱动器匹配和轮端热容量未确认；轮体完全是待设计项。

所有种子部件的初始状态均为 `source_recorded`。种子脚本更新来源内容时，不得自动把状态提升为 `engineer_reviewed` 或 `supplier_confirmed`，也不得把后续确认状态降级。

## 5. OpenModelica 阻断项

本版本没有执行指定 OpenModelica 版本的编译和数值回归，因此不能声称：

- 新平台已经生成并验证 Modelica 模型；
- 旧演示生成器输出已通过 OpenModelica 编译；
- 三维动画等价于多体动力学仿真；
- FMU 或联合仿真结果已达到实机精度。

关闭该阻断项至少需要：

1. 写明 OpenModelica 与 Modelica Standard Library 版本及运行环境；
2. 固定待验证模型、参数、初始条件和求解器设置；
3. 实际执行模型检查、编译和仿真，保存原始日志；
4. 明确数值容差、参考解或独立计算基准；
5. 对关键工况做数值回归并保存结果；
6. 对失败、奇异、参数不兼容和边界工况建立负向测试；
7. 由控制或多体仿真工程师复核模型假设与适用范围。

完成前，发布清单继续保持 `blocked`。

## 6. 专业复核记录最低字段

每份复核记录至少包括：

- 项目编号、版本号和快照内容摘要；
- 模块实例、模块版本和工程规则版本；
- 部件制造商、完整型号、修订和官方来源；
- 输入需求、工程假设和载荷谱来源；
- 使用公式、手算或独立工具结果；
- 偏差、警告、阻断项和处置结论；
- 复核人、专业、日期和签名或受控电子审批；
- 供应商确认文件及适用订货型号；
- 未关闭问题、责任人和重新验证条件。

## 7. 禁止对外误述

在证据补齐前，不使用“已验证选型”“可直接制造”“实机可用”“安全认证”“供应商已确认”“Modelica 编译通过”等表述。可以准确描述为：客户试点自动配置版、可修改方案草案、方案初算、来源已记录、参数化布局、项目与计算可追溯。
