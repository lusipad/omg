# UR5e 与 Robotiq 2F-85 取放工位

工位将独立导入的 UR5e、Robotiq 2F-85 和 30 mm 工件组成一个 MuJoCo 场景。打开装配包的 `workcell.xml`，选择 `pick_ready` 初始姿态，运行 10 秒的取放工况。默认主观测量为工件刚体 `part_cube` 的世界坐标，对照量为夹爪 `grip_pinch` 标记点的世界坐标。[独立工件 MJCF](./workpiece.xml)

## 装配和物理参数

| 部件 | 装配方式 |
| --- | --- |
| 机械臂 | 使用上游 UR5e 的六个关节和原始位置执行器，从模型内读取 `wrist_3_link` 的 `attachment_site` 位姿。 |
| 夹爪 | 用 MJCF 的 `attach` 将 `base_mount` 安装至法兰，沿用源模型 7 mm 安装座偏移、双侧四杆机构、联动腱、指垫接触参数与 `fingers_actuator`。装配后的夹爪名称带 `grip_` 前缀。 |
| 工件 | 30 × 30 × 30 mm，质量 27 g，初始中心为 (−135, 480, 195) mm。一个自由关节允许三个平移和三个转动自由度。滑动、扭转、滚动摩擦参数分别为 0.8、0.005、0.0001。 |
| 放置台 | 台面高 180 mm，机器人基座固连世界。松开后由台面支撑方块。 |

机械臂与夹爪取自 MuJoCo Menagerie 的固定提交 `71f066ad0be9cd271f7ed58c030243ef157af9f4`。装配包在 `arm/` 和 `hand/` 中各自保留原始机器人描述、所引用的网格、许可证与归属文件。夹爪原模型的约束位于左右指的连杆机构内部。工件与夹爪之间通过指垫接触和摩擦传力。[UR5e 原始描述](https://github.com/google-deepmind/mujoco_menagerie/tree/71f066ad0be9cd271f7ed58c030243ef157af9f4/universal_robots_ur5e) · [2F-85 原始描述](https://github.com/google-deepmind/mujoco_menagerie/tree/71f066ad0be9cd271f7ed58c030243ef157af9f4/robotiq_2f85)

两个上游模型均采用 BSD-3-Clause。UR5e 的版权标记为 `Copyright 2018 ROS Industrial Consortium`，2F-85 的版权标记为 `Copyright (c) 2013, ROS-Industrial`。构元工作台生成了装配入口、桌面、方块和对应的动作配方。[UR5e 许可证](https://github.com/google-deepmind/mujoco_menagerie/blob/71f066ad0be9cd271f7ed58c030243ef157af9f4/universal_robots_ur5e/LICENSE) · [2F-85 许可证](https://github.com/google-deepmind/mujoco_menagerie/blob/71f066ad0be9cd271f7ed58c030243ef157af9f4/robotiq_2f85/LICENSE)

## 动作配方

装配包的 `pick-place.json` 记录三个组件的相对入口、安装接口、初始控制、执行器名称与阶段目标。前六路控制为手臂的位置指令，单位为 rad。第七路使用夹爪原生的 0 至 255 标度，张开取 0，抓取取 200。

用已装夹爪、手臂处于上游 `home` 姿态时的工具朝向固定各目标方向。取件和放件的世界坐标 XY 分别为 (−135, 480) 和 (−55, 480) mm。工具 `grip_pinch` 在准备、取件、抬升、横移、放件和退让时的名义高度依次为 259、199、249、249、197.5 和 269 mm。

手臂关节目标由该装配模型的数值逆运动学求得，各静止目标再按手臂和夹爪的重力矩除以位置增益补偿。各阶段之间按 `3u² − 2u³` 平滑改变执行器指令。仿真以 2 ms 步长计算动力学，每 20 ms 记录一次。

| 时间（s） | 操作 |
| --- | --- |
| 0–1.15 | 从上方下降，张爪到达取件位。 |
| 1.15–2.00 | 闭合指垫并保持，2.00 s 作为稳定夹紧的测量起点。 |
| 2.00–4.00 | 名义竖直上举 50 mm 并悬空保持。 |
| 4.00–5.65 | 名义沿世界 X 轴横移 80 mm 并保持。 |
| 5.65–7.40 | 下降至新位置，使工件重新得到台面支撑。 |
| 7.40–10.00 | 张开夹爪并向上退让。 |

## 默认工件验证

以下数值来自 MuJoCo 4.0.1 WASM，采用源模型参数、刚性装配、椭圆摩擦锥和柔性接触求解。夹爪与工件高度为同一次积分中的独立观测。

| 比较 | 结果 |
| --- | --- |
| 2.00 至 4.00 s 的实测上举 | 工具 49.727 mm，方块 49.712 mm。 |
| 夹紧至横移保持结束，2.00 至 5.65 s | 方块中心在夹爪坐标系内相对 2.00 s 的最大采样位移为 0.085 mm。 |
| 悬空，4.00 s | 工件同时与左右指垫保持正法向接触力，已离开台面。 |
| 放回，7.40 s | 台面与指垫均接触工件。 |
| 松开并退让，10.00 s | 方块中心为 (−54.965, 480.385, 194.892) mm，相对初始位置沿 X 移动 80.035 mm，最终由台面支撑。 |
| 张爪对照 | 保持完全相同的手臂指令，全程将第七路置零。方块留在初始取件位置，10 s 内中心总位移最大为 0.172 mm，主要来自初始接触沉降。 |

替换工件可以通过同一 `cube` 自由刚体和 `block` 碰撞盒接口提供不同质量与摩擦。更换部件或参数后应重新运行并核对夹持滑移和松开后的落点。
